# Development provenance

This public repository began with a v1.0.0 release snapshot. Earlier local development commits were excluded because they contained personal Git identity information. The public snapshot is not a claim of independent or unaided authorship.

Codex contributed substantially to research, implementation, tests, cleanup and bug fixing. No claim is made that most code was written without generative AI.

The project began with the official Steam Deck Homebrew Decky Plugin Template. Home render hooks and per-client installation handling were adapted using Deck Shelves / Jonathan Santos as a technical reference. The upstream notices and bundled dependency sources/licenses remain in LICENSE, THIRD_PARTY_NOTICES.md and third-party/.

The [Decky Store submission #1138](https://github.com/SteamDeckHomebrew/decky-plugin-database/pull/1138) was closed without merging on October 8, 2026. The maintainer [acknowledged the inaccurate AI checkbox and substantial AI involvement](https://github.com/SteamDeckHomebrew/decky-plugin-database/pull/1138#issuecomment-6065879528). Clearly Recent remains available on GitHub for manual installation.

Development has concluded for this release. Final reported Stable/Beta test coverage and its limitations are summarized in the [README](../README.md#compatibility). No future version or independent third-party testing is promised.
