# Changelog

## 1.0.0

- Initial public release preparation.
- Hides Steam games that are not installed locally from Home Recent Games.
- Preserves installed games and Non-Steam shortcuts.
- Uses conservative fail-open handling for unknown app states.
- Uses the native Steam Home Recent carousel.
- Minimal status panel; works automatically while loaded.

Earlier development versions are preserved in Git history and the working-version backup tag.
